## Key facts
- **Name:** the game is called **Geography Speedrun**; the repo (and so the web address) is **Geography-Quiz**.
- **Live site:** https://sad-cpu141.github.io/Geography-Quiz/ (GitHub Pages, `main` branch, root folder).
- **Repo:** Sad-CPU141/Geography-Quiz. **Hub:** Sad-CPU141/sad-cpu141.github.io has a card for it. **Siblings:** Draft Night, Khatfa, Jeopardy-Board, Barra Al-Salfa (it copies their look, loads nothing from them).
- **Look:** the family ink/purple palette with gold; this game's accent is sky blue `#5aa8ff`. Fonts self-hosted in `fonts/`.
- **Tech:** plain JavaScript, no React, no bundler. Edit `src/`, then `npm run build`. Never edit `index.html`, `app.js`, `data.js`, `map.js`, `styles.css` or `sw.js` at the root by hand.
- `src/js/*.js` are joined in name order into `app.js` inside one function: `00-core` (data, matching, runs, codes, ranking — no DOM; exposed as `window.GS`, tested by `tests/run.js`), `10-ui` (DOM helper, home, setup, code entry, best times), `20-session` (sessions, clock, board run flow, give up, Quick fire), `30-grid` (flags/shapes/capitals boards), `40-map` (map games: map / flagmap / mapname), `45-borders-duel` (Borders, Bigger country), `50-results`, `60-live` (online race), `90-start`.
- `src/data.js` + `flags/` come from `tools/data.js` (`npm run data`): world-countries (ODbL), world-atlas/Natural Earth, and flags from svg-country-flags (Wikipedia SVGs, public domain) in their **real proportions** (`ratio` in the data; Monaco 5:4 ≠ Indonesia 3:2). Flags that changed after that set (Kyrgyzstan 2023, Syria 2025) come from flag-icons, widened to their real ratio (`NEWER_FLAGS`). Afghanistan uses the white Shahada flag (owner's choice): `tools/afghan-flag.mjs` lays out the Shahada with HarfBuzz in Amiri Bold and writes the letter shapes as paths to `tools/flags/af.svg` (no font needed on the device; the owner said the earlier text version looked DIY); `NEWER_FLAGS.AF` reads that file. Check for newer flag changes when updating. Accepted spellings (`NAME_ALIASES`), capitals (`CAPITALS`) and outline crops (`BOX`, `KEEP_ALL`) live there.
- `src/map.js` comes from `tools/map.js` (`npm run map`): Natural Earth projection, a world map and a Pacific-centred one (for Oceania), marker data (`mk`) for small countries, region views, and the world view's two insets (Caribbean, Pacific). Loaded only when a run has the Map game.
- **Online race** (`60-live.js`): Firebase Realtime Database (project `geography-speedrun`, owner's free Spark plan) + anonymous sign-in. SDK self-hosted in `vendor/firebase/` (compat builds v11, Apache-2.0), loaded only when you go online. Rules in `database.rules.json` (paste into Firebase console → Realtime Database → Rules). `NET` = backend layer; `?net=local` uses a localStorage stand-in (tests; the sandbox can't reach Firebase, and the emulator can't be downloaded). Home → 🌐 Online screen (`onlineHub`): Host match (→ setup with Online picked → Create room), Join a match (5-letter code, 📷 Scan QR — BarcodeDetector or jsQR — or a `?room=CODE` link), and Challenge code entry. Lobby shows the code, a QR code (qrcode-generator) of the join link, the link with Copy, and Share. QR libs self-hosted in `vendor/qr/` (MIT / Apache-2.0), loaded on demand; the host starts → shared start time 4 s later; progress sent on change + every 3 s; live standings bar; results update live; host can start another round (new seed). Analytics deliberately not used.
- **Israel is not in the game** (owner's decision): `LEAVE_OUT` in tools/data.js; it's grey on the map. 196 countries.

## Game rules
- **Full board** (default): pick any games in any order and a region. One clock for the whole run; it ends after the last game. Main games: Flags, Map, Capitals, Shapes. **More games** (fold-out in setup, `more: true` in GAMES — keep GAMES order, it's in the codes): Reverse Capitals (board of capitals → type the country), Map: name it (a country glows gold, type its name; the view zooms to it if it's small/off screen), Borders (`45-borders-duel.js`: name every land neighbour, any order; one point per border; `nb` in data = two-way borders from world-countries, only countries in the game), Flag → Map (tap the flag's country), Bigger country (20 rounds max, tap the larger land area; pairs always >10% apart; `area` from world-countries), Guess the language (`langGame` in 45-borders-duel.js: a sentence, pick its language from 4, keys 1–4).
  - Guess the language data: `src/langs.js` (`window.GS_LANGS`, loaded on every page) from `node tools/langs.mjs` — the official languages of the game's countries (world-countries) that have a full UDHR translation in the `udhr` package; the sentence is Article 1 (`text`) plus 2 short ones from Articles 3–6 (`more`). 116 languages; ~20 official ones have no UDHR text and are left out (the script prints them). Up to 20 rounds of the region's languages; a region with under 10 (North America has 4) is topped up to 10 with their other sentences (round ids `eng~1`). Wrong options: same writing system, up to 2 from the same continent first; never a near-identical language (`close`: Bosnian/Croatian/Montenegrin/Serbian, Indonesian/Malay, Persian/Dari, Sesotho/Sepedi/Setswana). Rare scripts use self-hosted Noto fonts (`'GS Scripts'` in styles.css, unicode-range, downloaded only when needed).
  - Flags / Shapes / Capitals (JetPunk style): every country is a big tile, all in a random order (new order every new run; the same code = same order). One tile is selected; typing its answer fills it in the moment it's right and selects the next empty tile. Tap a tile or ◀ ▶ (or Tab / arrow keys) to switch. **Enter never moves on**: on a wrong answer it just shakes (owner's request).
  - Map (Seterra style): it names a country (random order), you tap it. Colour by attempt: green / yellow / orange; 3 wrong taps → it flashes red, counts as missed, and you must tap it to go on (clock keeps running). Skip sends it to the back. Pinch/drag/wheel/+−. ⤢ toggles between the start view and the whole region; a phone held upright starts on a tighter view (`tight` boxes in tools/map.js) showing 70% of its width. Grey = not in the game.
  - Small countries, Seterra style: a small white dot when a country is under 9 px on screen; a dashed box round a spread-out island group; on the World map (screen ≥ 620×380, not zoomed in) magnified Caribbean and Pacific insets (bottom corners), and the main map hides dots/boxes for the countries an inset covers. Found dots/boxes light up in the answer colour; a right tap pops and shows a green ✓ name bubble, a wrong tap a red ✗ bubble with what you tapped; progress bar (found green / missed red); mouse hover highlights countries; results show first-tap accuracy. Taps: what's under the finger wins; else a country within 3–10 px; else the nearest dot/box within 16 px (only within the same inset).
  - Give up: reveals the misses (red) with the clock paused; then next game, or "End the whole run" (later games count as all missed).
  - Ranking: most found, then fastest.
- **Quick fire**: one question at a time, type or pick from 4, penalties (skip +10 s, wrong +5 s), lowest time wins.
- **Spelling help** (setup switch, off by default, not part of the challenge code; results say "With spelling help"): when what you typed is close (edit distance 1–3 by length) to any country/capital in the world, it shows "Did you mean X?" (up to 2). Tapping it (or Enter with one suggestion) tries it like a typed answer. `suggest()` in 00-core.
- Matching ignores case, accents, punctuation, spaces, a leading "the"; "Saint"="St"; "City" at the end / "City of" at the start is optional. An answer is accepted the moment it matches (e.g. "Bosnia").
- **Practice** (setup switch, board runs you start yourself): no clock (timer shows "Practice"), a 👁 Show answer / Show button in every game (counts as missed), no best times, no daily score, no challenge card.
- **My misses** (home button, appears once you've missed something): per game, how often each country was missed minus how often it was got right since (`gs_misses_v1`, `recordMisses`), for flags/shapes/capitals/revcap/map/mapname/flagmap (+ Quick fire). Practice button = practice run of your top 30 misses for that game (`cfg.custom`).
- **Text:** the owner wants it minimal — short labels, no explaining sentences under buttons.
- **Daily run** (home page card): same for everyone each day, changing at midnight Eastern time (`todayNum`, America/Toronto) — `dailyCfg(day)`: a continent in turn + 2 games from flags/map/capitals/shapes/revcap/flagmap. First finished go of the day is kept (`gs_daily_v1`), streak shown, share text + link.
- Challenge code: runs that use any More game get a longer code (10+ chars, `encodeLong`: n−1 4 bits, games 4 bits each, region 3 — games+region scrambled — seed 21, check 6). Otherwise 8 chars Crockford base32 = K 15 bits (kind 1 + quick: mode 2, region 3, style 1, count 8 | board: game order 6 (index into 64 orders), region 3, zeros 5) scrambled with the seed, seed 21, check 4. Links: `?c=CODE&n=name&t=ms&s=found` (honour system).
- Pass the phone: 2–8 names, same run each, leaderboard.
- Best times are per kind of run, in `localStorage` key `gs_best_v2`.
