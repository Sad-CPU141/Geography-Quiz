## Key facts
- **Name:** the game is called **Geography Speedrun**; the repo (and so the web address) is **Geography-Quiz**.
- **Live site:** https://sad-cpu141.github.io/Geography-Quiz/ (GitHub Pages, `main` branch, root folder).
- **Repo:** Sad-CPU141/Geography-Quiz. **Hub:** Sad-CPU141/sad-cpu141.github.io has a card for it. **Siblings:** Draft Night, Khatfa, Jeopardy-Board, Barra Al-Salfa (it copies their look, loads nothing from them).
- **Look:** the family ink/purple palette with gold; this game's accent is sky blue `#5aa8ff`. Fonts self-hosted in `fonts/`.
- **Tech:** plain JavaScript, no React, no bundler. Edit `src/`, then `npm run build`. Never edit `index.html`, `app.js`, `data.js`, `map.js`, `styles.css` or `sw.js` at the root by hand.
- `src/js/*.js` are joined in name order into `app.js` inside one function: `00-core` (data, matching, runs, codes, ranking — no DOM; exposed as `window.GS`, tested by `tests/run.js`), `10-ui` (DOM helper, home, setup, code entry, best times), `20-session` (sessions, clock, board run flow, give up, Quick fire), `30-grid` (flags/shapes/capitals boards), `40-map` (map games: map / flagmap / mapname), `45-borders-duel` (Borders, Bigger country, Guess the language), `47-more-games` (Border chain, Hot or cold, Closer or further, Clue reveal, Letter rush, Unscramble, Currency & people, Flag finder), `50-results`, `60-live` (online race), `90-start`.
- `src/data.js` + `flags/` come from `tools/data.js` (`npm run data`): world-countries (ODbL), world-atlas/Natural Earth, and flags from svg-country-flags (Wikipedia SVGs, public domain) in their **real proportions** (`ratio` in the data; Monaco 5:4 ≠ Indonesia 3:2). Flags that changed after that set (Kyrgyzstan 2023, Syria 2025) come from flag-icons, widened to their real ratio (`NEWER_FLAGS`). Afghanistan uses the white Shahada flag (owner's choice): the owner supplied the real (public-domain Wikipedia) flag as `tools/flags/af-source.png`; `tools/afghan-flag.mjs` traces it with potrace into `tools/flags/af.svg`, which `NEWER_FLAGS.AF` reads. Don't redraw it with a font — the owner said that looked DIY. Check for newer flag changes when updating. Accepted spellings (`NAME_ALIASES`), capitals (`CAPITALS`) and outline crops (`BOX`, `KEEP_ALL`) live there.
- `src/map.js` comes from `tools/map.js` (`npm run map`): Natural Earth projection, a world map and a Pacific-centred one (for Oceania), marker data (`mk`) for small countries, region views, and the world view's two insets (Caribbean, Pacific). Loaded only when a run has the Map game.
- **Online race** (`60-live.js`): Firebase Realtime Database (project `geography-speedrun`, owner's free Spark plan) + anonymous sign-in. SDK self-hosted in `vendor/firebase/` (compat builds v11, Apache-2.0), loaded only when you go online. Rules in `database.rules.json` (paste into Firebase console → Realtime Database → Rules). `NET` = backend layer; `?net=local` uses a localStorage stand-in (tests; the sandbox can't reach Firebase, and the emulator can't be downloaded). Home → 🌐 Online screen (`onlineHub`): Host match (→ setup with Online picked → Create room), Join a match (5-letter code, 📷 Scan QR — BarcodeDetector or jsQR — or a `?room=CODE` link), and Challenge code entry. Lobby shows the code, a QR code (qrcode-generator) of the join link, the link with Copy, and Share. QR libs self-hosted in `vendor/qr/` (MIT / Apache-2.0), loaded on demand; the host starts → shared start time 4 s later; progress sent on change + every 3 s; live standings bar; results update live; host's "Another round" (`liveNextRound`) opens the setup game list in next-round mode (`S.liveNext`: no Style/Who cards, "▶ Start round N" → `liveStartRound(cfg)`; back arrow → room lobby); others see "The host is picking the next round…" (`room.picking`). **Nobody sees a friend's score until that friend finishes** — not in the live bar during the race (you see your own count) and not on the results; a friend still playing shows which game they're on (`livePeek`: "🏛️ Capitals", from the `sec` they report), or just "playing…" if the host turned off 👀 See what game others are on (`cfg.noPeek`, setup switch shown for Online). `liveCfg(cfg, st)` adds the room-wide settings (only when on — Firebase can't store undefined). **Spelling help is the room's setting** (`cfg.help` from the host; `startSession` uses `cfg.help` when present, else your own switch). **Head to head** (`h2hRecord`/`h2hCard`): when everyone in a round has finished, each rival counts a win/loss/tie on this device (`gs_h2h_v1`, keyed by their Firebase uid; `gs_h2h_seen_v1` stops double counting); shown on live results ("You vs Sam 7 – 4") and on the Online screen. Analytics deliberately not used.
- **Israel is not in the game** (owner's decision): `LEAVE_OUT` in tools/data.js; it's grey on the map. 196 countries.

- **Updates:** `sw.js` fetches app files with `cache: 'no-cache'`; `checkUpdate()` (90-start) compares `version.json` with `APP_VERSION` on open, on return to the tab and every 10 min, and reloads on the home screen (or next time you go home; never mid-run; once per version via sessionStorage).

## Game rules
- **Setup games picker** (owner: Roblox style): "Your run" lists the picked games in order (↑ ↓ ✕, and a "how many" select per game); "＋ Add games" opens `gameBrowser()` (10-ui): a sheet of cards — a picture of the game (`gameArt`, built from real flags/outlines/text, no artwork), its name and ＋; tabs All + `GAME_CATS`; tapping a card shows a bigger picture, description and example (`GAME_INFO`). Every non-retired game must be in a tab (test).
- **How many per game** (`cfg.counts`, setup select; `GAME_COUNTS` in core): country games take N countries (normal = all), others N rounds/puzzles/letters (normal = their default). In codes as `+Q5.0.1` (one number per game in order, 0 = normal), in room cfgs, best-time keys and the run name ("Flags ×5").
- **Newer games (Oct 2026, GAMES index 11+ → codes use 5 bits per game and end in "+V")**: 🔗 Border chain (Travle style — only the start, the end and your guesses are drawn, nothing else: get from A to B over land; type countries, coloured green = on a shortest route, orange = ≤2 steps off, red = off; solved when your countries join A to B; guesses = shortest-in-between + 4; then "Shortest: A → … → B"; 5 puzzles 2–5 apart; map framed on the countries' main parts, dots for tiny ones; `hops`/`shortestRoute` BFS over the two-way borders). 📝 Name them all (map mode 'all' in 40-map: no prompt, type any country of the run, it lights up; the all-countries-tappable option never applies to it). 🔥 Hot or cold — Globle style (owner): a 3D globe (d3-geo orthographic, vendor/d3 ISC, loaded on demand with src/globe.js outlines from tools/globe.mjs — Natural Earth 110m/50m, degrees×5, rings kept the small way round; 6 tiny countries are circles); each guess is painted by the distance between nearest borders (`borderKm`, 0 = bordering → dark red; pale = far), list sorted by distance; unlimited guesses, Reveal = missed; drag to spin, auto-turns to each guess; 3 mystery countries. 📏 Closer or further (20 "t|a|b" rounds; harder: the two distances 7–22% apart; keys 1/2). 🕵️ Clue reveal (10 countries; one clue to start, each wrong guess (a real country) shows the next; clues hardest-first: size, coast + neighbour count, languages, continent, sub-region, currency, capital's first letter, neighbours, flag, first letter + length; Pass = missed). 🔤 Letter rush (5 letters × 12 s; name as many countries of the run starting with it as you can; wrong ones don't count). 🔀 Unscramble (15; letters shuffled word by word). 💰 Currency & people — REMOVED by the owner (`retired: true` in GAMES so codes keep their places; not in any tab; setup drops it). 🔎 Flag finder (Seterra style: a name, find its flag in the grid; found/missed flags move to the back; 3 wrong → it flashes, tap it). Facts come from world-countries via tools/data.js (`ll` centre, `land`, `sub`, `cur`, `lang`, `dem`). One shot also applies to Unscramble and Currency & people. `NEEDS_MAP` = games that load the map (incl. Border chain). A game with nothing to ask is skipped.
- **Full board** (default): pick any games in any order and a region. One clock for the whole run; it ends after the last game. Main games: Flags, Map, Capitals, Shapes. **More games** (fold-out in setup, `more: true` in GAMES — keep GAMES order, it's in the codes): Reverse Capitals (board of capitals → type the country), Map: name it (a country glows gold, type its name; every new one: `flyTo` — a smooth zoom-out/travel/zoom-in ending with it centred at ~28% of the screen, never closer than 1/10 of the region; `boxOf` centres on the main part, e.g. mainland France; dragging/zooming stops the flight; "Animation speed" slider 1–10 on the map's top-left, 10 = Off, saved as `gs_anim_v1`, default 6; the ✓ bubble shows at the top of the map), Borders (`45-borders-duel.js`: name every land neighbour, any order; one point per border; `nb` in data = two-way borders from world-countries, only countries in the game), Flag → Map (tap the flag's country), Bigger country (20 rounds max, tap the larger land area; pairs always >10% apart; `area` from world-countries), Guess the language (`langGame` in 45-borders-duel.js: a sentence, pick its language from 4, keys 1–4).
  - Guess the language data: `src/langs.js` (`window.GS_LANGS`, loaded on demand) from `node tools/langs.mjs` — the official languages of the game's countries (world-countries) that have a full UDHR translation in the `udhr` package; each language has up to 12 sentences (`texts`: Article 1, then the first sentence of other articles, 25–170 chars); every round picks one at random (round id `ara~3` = language + sentence), so a language isn't always the same sentence (owner: no patterns). `src/langs.js` (~210 KB) is NOT in the page: `needLangs()` (20-session) loads it when a run with the language game starts (also the lobby preloads it, the daily result loads it); `langsReady()` in core picks it up. 116 languages; ~20 official ones have no UDHR text and are left out (the script prints them). Up to 20 rounds of the region's languages; a region with under 10 (North America has 4) is topped up to 10 with their other sentences. Wrong options: same writing system, up to 2 from the same continent first; never a near-identical language (`close`, from `CLOSE` in tools/langs.mjs: e.g. Bosnian/Croatian/Serbian, Czech/Slovak, Danish/Norwegian/Swedish, Russian/Ukrainian/Belarusian, Kirundi/Kinyarwanda, Zulu/Xhosa/Swati/Ndebele). After each answer, "Spoken in" shows the flags of the countries where it's official. Rare scripts use self-hosted Noto fonts (`'GS Scripts'` in styles.css, unicode-range, downloaded only when needed).
  - Flags / Shapes / Capitals (JetPunk style): every country is a big tile, all in a random order (new order every new run; the same code = same order). One tile is selected; typing its answer fills it in the moment it's right and selects the next empty tile. Tap a tile or ◀ ▶ (or Tab / arrow keys) to switch. **Enter never moves on**: on a wrong answer it just shakes (owner's request).
  - Map (Seterra style): it names a country (random order), you tap it. Colour by attempt: green / yellow / orange; 3 wrong taps → it flashes red, counts as missed, and you must tap it to go on (clock keeps running). Skip sends it to the back. Pinch/drag/wheel/+−. ⤢ toggles between the start view and the whole region; a phone held upright starts on a tighter view (`tight` boxes in tools/map.js) showing 70% of its width. Grey = not in the game.
  - Small countries, Seterra style: a small white dot when a country is under 9 px on screen; a dashed box round a spread-out island group; on the World map (screen ≥ 620×380, not zoomed in) magnified Caribbean and Pacific insets (bottom corners), and the main map hides dots/boxes for the countries an inset covers. Found dots/boxes light up in the answer colour; a right tap pops and shows a green ✓ name bubble, a wrong tap a red ✗ bubble with what you tapped; progress bar (found green / missed red); mouse hover highlights countries; results show first-tap accuracy. Taps: what's under the finger wins; else a country within 3–10 px; else the nearest dot/box within 16 px (only within the same inset).
  - Give up: reveals the misses (red) with the clock paused; then next game, or "End the whole run" (later games count as all missed).
  - Ranking: most found, then fastest.
- **Quick fire**: one question at a time, type or pick from 4, penalties (skip +10 s, wrong +5 s), lowest time wins.
- **Spelling help** (setup switch, off by default, not part of the challenge code; results say "With spelling help"): when what you typed is close (edit distance 1–3 by length) to any country/capital in the world, it shows "Did you mean X?" (up to 2). Tapping it (or Enter with one suggestion) tries it like a typed answer. `suggest()` in 00-core.
- Matching ignores case, accents, punctuation, spaces, a leading "the"; "Saint"="St"; "City" at the end / "City of" at the start is optional. An answer is accepted the moment it matches (e.g. "Bosnia").
- **Where** (setup): one region, 🎲 Mixed (N random countries from the world, number box, board runs only; `cfg.limit`), or 🗺️ Pick several (switch → toggle any continents; `cfg.regions`, region = 'world'). `withWhere` tidies it (1 continent → that region, all 6 → world); `cfgPool(cfg, gameIndex)` is a game's countries (Mixed: each game gets its OWN random N — owner: the same ones in every game give the pattern away; new seed → new picks; without an index it's the whole pool); `whereLabel` ("Africa + Europe", "Mixed 30", "Asia + Oceania · 15 random"). Code suffix `+R<mask>` (bit i = CONTINENTS[i]) and `+C<n>`. Map view for several continents = the box round them on the world map (`mapView` in 40-map; the whole world if Oceania is in).
- **Run options** (setup switches, only shown with the games they apply to; `withOpts` in 00-core): 🧱 Map: no borders (`cfg.hard` — map/flagmap/mapname draw country borders in the land colour, no hover hint; answered ones still get coloured) and ⌨️ Languages: type it (`cfg.langType` — type the name, `langAnswer` accepts the name, its bracket parts and `alt` names from tools/langs.mjs; Enter on wrong shakes; Pass shows the answer). They ride in the challenge code after a "+" (`ABCD-1234+NT`), in online room cfgs, best-time keys and the run name (· No borders / · Typed).
- **🎯 One shot** (`cfg.strict`, code letter E; switch shown when the run has a typing game — flags/shapes/capitals/revcap/mapname/borders, or lang with Typed): answers only go in with Enter; a wrong one is missed (answer shown in red) and it moves on (borders: the rest of that country's neighbours). Works with spelling help: suggestions still show, and tapping one (or Enter with one suggestion) is your answer — wrong = missed (`onWrong` in `spellingHelp`).
- **🌍 Map: all countries tappable** (`cfg.allMap`, code letter A; switch shown with a map game): every country on the map is live (no grey), so when the run only has some (Mixed, one continent) you can't tell the answers by colour; tapping one outside the run is a wrong try.
- **Progress text** in every game says what's left, not just the score: "5 found · 41 left", "12 borders · 30 countries left", "3 right · 17 left".
- **Practice** (setup switch, board runs you start yourself): no clock (timer shows "Practice"), a 👁 Show answer / Show button in every game (counts as missed), no best times, no daily score, no challenge card.
- **My misses** (home button, appears once you've missed something): per game, how often each country was missed minus how often it was got right since (`gs_misses_v1`, `recordMisses`), for flags/shapes/capitals/revcap/map/mapname/flagmap (+ Quick fire). Practice button = practice run of your top 30 misses for that game (`cfg.custom`).
- **Dialogs:** never the browser's confirm()/prompt() (owner: they look generic). Use `ask(title, yesLabel, onYes, note)` and `copyBox(title, text)` in 10-ui (built on `modal()`, Escape/tap outside closes).
- **Text:** the owner wants it minimal — short labels, no explaining sentences under buttons.
- **Daily run** (home page card): same for everyone each day, changing at midnight Eastern time (`todayNum`, America/Toronto) — `dailyCfg(day)`: a continent in turn + 2 games from flags/map/capitals/shapes/revcap/flagmap (+ lang from 29 Oct 2026, `LANG_DAILY_FROM`, so earlier days keep their run). **One go per day per device** (owner's rule): pressing Go writes `{left:true}` to `gs_daily_v1[day]` (leaving early uses up the day); finishing saves time/score + per-game `sections`; after that the card shows your score and opens `dailyResult(day)` (time, score, misses per game); `startSession` refuses a played day; no "Same order" on daily results. Streak shown, share text + link.
- Challenge code: runs that use any More game get a longer code (10+ chars, `encodeLong`: n−1 4 bits, games 4 bits each, region 3 — games+region scrambled — seed 21, check 6). Otherwise 8 chars Crockford base32 = K 15 bits (kind 1 + quick: mode 2, region 3, style 1, count 8 | board: game order 6 (index into 64 orders), region 3, zeros 5) scrambled with the seed, seed 21, check 4. Links: `?c=CODE&n=name&t=ms&s=found` (honour system).
- Pass the phone: 2–8 names, same run each, leaderboard.
- Best times are per kind of run, in `localStorage` key `gs_best_v2`.
