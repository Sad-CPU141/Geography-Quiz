## Game rules
- Modes: flags, shapes, capitals, mix. Regions: world + 6. Lengths: 10/25/50/all (world) or 10/20/all.
- Type mode: the answer is checked on every keystroke against the current question only and moves on when right. Matching ignores case, accents, punctuation, spaces, a leading "the"; "Saint"="St"; "City" at the end / "City of" at the start is optional. Skip = +10 s.
- Pick mode: 4 options from the same region. Wrong = +5 s and the right one is shown.
- The clock pauses while the right/wrong answer is on screen (180 ms / 1 s), so feedback costs nobody time. Final time = clock + penalties. Lowest time wins.
- Challenge code: 8 chars Crockford base32 = mode 2 bits, region 3, style 1, count 8, seed 22, check 4 (settings bits scrambled with the seed). Same code → same questions and options. Links: `?c=CODE&n=name&t=ms&s=correct` (honour system; the time in a link can be edited).
- Pass the phone: 2–8 names, same run each, cover screen between players, leaderboard.
